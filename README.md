# Yeter!

Boşa para harcama dürtüsüne karşı bir fren. Hedefini koy (ör. aylık Claude Pro $20), dürtüye direndikçe hedefe yaklaş.

## Özellikler
- **Canlı birikim sayacı:** Harcanmayan her saniye birikime işler.
- **Dürtü akışı:** DUR butonu, 10 dakikalık bekleme ve "gerçekten ihtiyacım var mı?" sorgusu. Vazgeçilen tutar birikime eklenir.
- **Çoklu hedefler:** TL veya USD hedefler, aylık tekrar eden hedefler, canlı geri sayım (gün:saat:dk:sn).
- **Günlük otomatik kur:** USD/TRY kuru günde bir kez güncellenir.
- **Yerel veri:** Veriler cihazda tutulur.

## Otomatik APK Derleme
GitHub Actions her push'ta APK'yı derler ve Releases bölümüne yükler.
