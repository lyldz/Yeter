# Yeter!

Boşa para harcama dürtüsüne karşı bir fren. Hedefini koy (ör. aylık Claude Pro $20), dürtüye direndikçe hedefe yaklaş.

## Özellikler
- **Canlı birikim sayacı:** Harcanmayan her saniye birikime işler.
- **Dürtü akışı:** DUR butonu, 10 dakikalık bekleme ve "gerçekten ihtiyacım var mı?" sorgusu. Vazgeçilen tutar birikime eklenir.
- **Çoklu hedefler:** Her biri kendi para biriminde, aylık tekrar eden hedefler, canlı geri sayım (gün:saat:dk:sn).
- **8 para birimi, canlı kur:** TRY, USD, EUR, GBP, CHF, JPY, CAD, AUD; kurlar arka planda güncellenir.
- **Her sabah tasarruf sorusu:** O günün tutarı saniye saniye birikir.
- **Bildirimler:** Sabah hatırlatması, hedefe yaklaşma ve ulaşma.
- **Yerel veri:** Veriler cihazda tutulur.
