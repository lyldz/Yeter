# Yeter!

Gereksiz harcamaları engelleyip sadece asıl hedeflere odaklanmayı sağlayan harcama kısıtlama ve birikim takip uygulaması.

## Özellikler
- **Günlük Kumbara / Harcamama Sayacı:** Para harcanmayan her gün kumbaraya eklenir.
- **Hedef ve Süre Hesaplayıcı:** Belirlenen hedef tutara (ör. 540 TL) günde harcanmayan miktar ile kaç günde ulaşılacağını canlı hesaplar.
- **Motivasyonel Bildirimler:** Hedefe ne kadar kaldığını ve biriken tutarı hatırlatır.
- **Yerel Veri Saklama:** İnternet bağlantısı gerektirmeden kayıtları cihazda tutar.

## Otomatik APK Derleme
GitHub Actions sayesinde her güncellemede Android APK'sı otomatik olarak derlenir ve Actions bölümünden indirilebilir.
